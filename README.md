### Lab 01
Introduction to HTML and basic web page structure. Covers fundamental HTML elements and page organization.

### Lab 02
Multi-page website with advanced features including:
- **Navigation Page**: Cross-page navigation implementation
- **Profile Page**: Personal profile with image and contact information

- **Schedule Page**: Data presentation using HTML tables

✅ **Consistent Navigation**: Same header and navigation menu on all pages
